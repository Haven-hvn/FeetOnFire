Latency Lab

Measures what this browser and this machine do to input, audio and video timing. Everything runs locally; nothing is uploaded. All times are milliseconds.

This page is not cross-origin isolated, so shared memory and fine timers are off and some measurements are less precise. Open it through npm run serve for full precision.

2. Input

    
Start a test, then press keys or step on the pad. Dispatch delay is how long an event waited before a handler ran. It does not include the time from the switch closing to the browser seeing the event; the tap test in section 5 measures that.

3. Audio

    
Reports the output latency the browser claims and how well the performance clock can be mapped to the audio being heard. Leave it running for a minute for a meaningful drift figure.
